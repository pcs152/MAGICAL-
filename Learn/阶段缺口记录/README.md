# 阶段缺口记录

这个文件夹用于记录各阶段已经跑通之后仍然不完善、需要后续补强的地方。

记录原则：

- 只记录“后续需要回来看”的问题，不在这里展开长篇方案。
- 每条记录尽量写清楚所属阶段、现象、为什么重要、后续可能动作。
- 当用户说“记录：...”时，把内容追加到 `open_issues.md`。
- 如果某条缺口后来已经解决，在原条目下追加“处理结果”，不要直接删除历史。

阶段示例：

- V0：小电路真实 PEX 样本闭环
- V1：寄生风险规则解释
- V2：接入 AnalogGym 中等/大电路
- V3：Graph Transformer baseline
- V4：Graph Diffusion 寄生建模
